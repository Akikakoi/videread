## 三、v2 新发现的问题

### R1 控制台用 window.alert() 做错误反馈 【高·一致性】
app.js 里 6 处 `window.alert()`（取消失败 / 收藏失败 / 改名失败 / 删除失败 / 连接失败）。原生 alert 阻塞主线程、无动画、与两套 UI 风格断裂——编辑风已有完整 toast 组件（入场+退场+降级），控制台却没有。这是当前全项目最明显的动画/反馈不一致。

### R2 editorial-live 两个小缺口 【低】
- `.stepper li { transition: color .3s }` —— token 化漏网之鱼（应 `var(--t)`）
- 新问答的"来信"插入列表时突现（insertAdjacentHTML 无入场动画），与全站"一切出现皆有过渡"的新基调不符；需只对**新插入项**做一次性动画（参照 stepper 的增量 diff 思路）

### R3 跨 UI 缓动曲线未统一 【低·手感】
编辑风 `cubic-bezier(.22,.61,.36,1)` vs 控制台 `cubic-bezier(0.23,1,0.32,1)`。两套内部各自一致，跨页切换时能感觉到节奏微差。建议编辑风向控制台靠拢（改一个 token 值即完成），或反向，二选一。

### R4 目录行 hover 位移 10px 【微】
与按钮 -3px 的幅度体系不成比例，建议 6px。

## 四、保护项（继续不做）

- 报告模板零动画（打印/导出场景，风险大于收益）
- 不引入动画库
- 不加视差/大动效——编辑风气质是"静"
