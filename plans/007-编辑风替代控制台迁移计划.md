### 放弃项（不迁移）

- 换背景图（上传 / 恢复）
- 遮罩设置（遮罩画布）
- 投印附加参数开关（2026-10-18 用户决策）：不提供 no_cache / keep_audio / asr_backend 的 UI 开关，策略固定——**忽略缓存强制重跑、不留音频文件、转写引擎按 .env 配置（"自动"= ASR_BACKEND 环境变量，非智能选择）**
- 连带：控制台的背景照片层、`--veil` 纱罩、相关 CSS 变量组随控制台退役自然消亡
- 后端 `/api/runs/{id}/background*`、遮罩端点**暂时保留**（无 UI 入口即无影响），控制台退役批次统一清理并删测试

### 保留资产（两边共用）

- API 契约全部不动
- 动效体系：token / reduced-motion / html.js 兜底（编辑风已成体系，控制台 toast 退役时按编辑风版收敛）
- 控制台 toast（本批已做）：迁移期间两套 UI 各自可用，最终收敛为编辑风版
